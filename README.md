# 📊 Dashboard — Consulta Fácil

## 📌 Sobre o projeto

Este dashboard foi desenvolvido como parte do **Projeto Integrador Consulta Fácil**, do curso de Análise e Desenvolvimento de Sistemas (ADS) da Faculdade Senac.

O objetivo é facilitar o acompanhamento dos agendamentos de consultas médicas, oferecendo indicadores e gráficos que auxiliam na tomada de decisões.

## 🚀 Funcionalidades

- Visualização do total de agendamentos.
- Quantidade e percentual de consultas canceladas.
- Distribuição dos agendamentos por especialidade.
- Filtros interativos por mês, especialidade e unidade de saúde.
- Atualização automática dos indicadores conforme os filtros selecionados.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- CSV para armazenamento dos dados demonstrativos.

## 💻 Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `dashboard_consulta_facil.html` no navegador.
3. Utilize os filtros para explorar os indicadores.

## 📊 Base de dados

O dashboard utiliza uma base de **240 agendamentos sintéticos**, criada exclusivamente para fins acadêmicos.

Os dados não representam pacientes ou atendimentos reais.
